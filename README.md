Activity 7 – Flowchart
Her ligger mit flowchart, som viser programmets struktur for opgaven "Conveyor Belt Capacity Check".
ConveyorBeltCapacityCheck
Dette er selve C#-programmet, der løser opgaven.
Programmet spørger brugeren om antal motorer og den totale pakkevægt.
Derefter beregner det vægten pr. motor ved at dividere totalvægt med antal motorer.
Hvis belastningen pr. motor er mindre end eller lig med 5.6 kg, kan transportbåndet bære pakkerne.
Ellers kan det ikke.
